# Wire to Wire — foaling country flags (SVG)

These icons use the 4:3 SVG artwork of [flag-icons](https://github.com/lipis/flag-icons) by Panayiotis Lipiridis, licensed under MIT. The full notice is retained as `LICENSE.flag-icons.txt` in this directory.

Current historical foaling geography in the repository includes: United States (us), Canada (ca), England (gb-eng), Ireland (ie), France (fr), Argentina (ar), Japan (jp), New Zealand (nz), Chile (cl), Great Britain (gb), Germany (de), and Puerto Rico (pr). Australia (au) is supplied for later racing-world expansion.

These are UI icons, **not** another country, horse or birthplace database. Display each icon only alongside approved foaling geography; do not infer a country from a horse's home track or barn. Puerto Rico has a distinct territorial flag; England is a constituent country of the UK and uses St George's Cross, while Great Britain uses the UK flag.

Use `/assets/flags/v1/<code>.svg` inside `<img>` tags. Text foaling geography must always remain alongside the icon for accessibility and clarity.
